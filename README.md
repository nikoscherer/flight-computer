# -- STM32Cube Project for Bulldog Rocketry Flight Computer --



## --- GNU ARM Toolchain ---
- Version: 15.3.Rel1

# How to install
- Go to https://developer.arm.com/tools-and-software/gnu-toolchain
- Click "Download Arm GNU Toolchain"
- Scroll down to "Available Releases"
- Click "Arm GNU Toolchain 15.3.rel1"
- Scroll down until you see "Windows hosted cross toolchains", "Linux hosted cross toolchains", and "macOS hosted cross toolchains"
- Click the dropdown for your current system
- Click "arm-gnu-toolchain-15.3.rel1-xxxxx-xxx-xxxx-arm-none-eabi.zip" that matches your system
- Open file explorer
- Go to downloads folder
- Right click the "rm-gnu-toolchain-15.3.rel1-xxxxx-xxx-xxxx-arm-none-eabi.zip" folder and click "extract all"
- Click Extract
- Open this project folder in another file explorer
- Create a folder called "tools"
- Copy "rm-gnu-toolchain-15.3.rel1-xxxxx-xxx-xxxx-arm-none-eabi" into tools/
- Rename "rm-gnu-toolchain-15.3.rel1-xxxxx-xxx-xxxx-arm-none-eabi" to gnu-arm-toolchain
